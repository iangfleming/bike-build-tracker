Refactor catagories

Currently there are groups > catagories > items. I'd like to flatten and reformat this to Catagories > items. The current default groups become the catagories and the catagories should become default items that can be either filled in with details and added to the build or deleted by the user if unnecessary. Provide a "clear defaults" button under build actions. Adding a new catagory shouldn't create any items by default. All catagories and items should be able to be deleted.
